## What stays local?

The model archive is fetched from the pinned Hugging Face revision. Your prompt, generated reasoning, tool arguments, and tool results stay in the page. The sample tool only returns `{ "flashlight": "on" }` and does not access device hardware.

For the most reliable first result, keep the default **“Turn on the flashlight.”** prompt. Needle is a compact action model; unrelated conversational prompts may correctly decline with `[]`.
