:::caution[Expect a deliberate first run]
The first click downloads 13.7 MB and compiles the selected engine. **Resident WebGPU** is the default; if initialization fails, the demo reports the fallback and uses pure TypeScript. CPU prefill may take a few seconds, especially on mobile. Later examples reuse the same in-memory model and browser cache.
:::

:::note[Animation during WebGPU inference]
Resident inference and the 3D room share the same physical GPU. The model runs in a dedicated worker, so the page remains responsive, but room animation may temporarily lose smoothness while WebGPU compute is active. Choose **Pure TypeScript** when animation smoothness matters more than inference speed.
:::

## Choose the execution engine

- **Resident WebGPU** keeps hidden lanes, KV cache, attention, engrams, confidence, and constrained token selection on the GPU. It requires browser WebGPU and TypeGPU.
- **Pure TypeScript** is the portable numerical reference and requires no GPU, WASM, or native addon.

Changing the selector disposes the loaded model and initializes the newly selected backend on the next run. The output panel always shows the backend that actually executed the request.

## What stays local?

The model archive is fetched from the pinned Hugging Face revision. Your prompt, generated reasoning, tool arguments, tool results, and simulated room state stay in the page. The smart-home tools only update this local bedroom visualization and do not access device hardware.

For the most reliable first result, choose one of the suggested light, curtain, fan, or room-status instructions. Needle is a compact action model; unrelated conversational prompts may correctly decline with `[]`.
